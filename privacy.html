Privacy notice

EtsyPulse AI App is a private application operated by its owner for their own business. This notice describes its Google Drive connections and related data processing.

Google Drive access

Receipts: a separate service-account connection requests the drive.readonly scope. The app is configured to list file metadata and download PDF receipts from the owner's selected folder and its subfolders. It extracts receipt details for expense records and retrieves PDFs for preview. This connection does not edit or delete the original Drive files.

Backups: the owner authorizes a separate connection using drive.file. When configured, the backup routine creates encrypted database snapshots in a dedicated Drive folder and can download them to verify recovery. It uses files created or authorized for this backup connection; it does not require access to the owner's existing receipt folder.

Local storage and backups

The application stores business records on owner-controlled storage. Expense records include extracted values, source metadata, extraction evidence and revision history. PDF contents can be staged temporarily in the database for extraction; those temporary contents are cleared after extraction or cancellation. Receipt previews are rendered locally in memory, and original documents remain in Drive or the owner's files.

The backup routine makes a consistent database copy in memory, removes Etsy OAuth tokens and authorization-state records from that copy, and encrypts it locally through rclone before upload to Drive. A recovery check downloads and decrypts a separate copy locally. The backup still contains private business data, and may include temporarily staged PDFs if extraction is pending. Application environment files, service-account key files and rclone credential files are stored separately and are not included in the database snapshot.

AI analysis and other services

Receipt extraction and PDF previews do not send raw PDFs or full receipt text to AI services. The backup routine does not call an AI service.

Configured shop and listing analyses can send selected shop evidence and structured expense information to Anthropic or Google Gemini, including a configured fallback provider. Expense information can include amounts, dates, currencies, categories, cost allocations, provenance and coverage. The recorded-expense projection excludes vendor names, payment-evidence text, private notes, receipt filenames and source locations. Analyses may be requested by the owner or run on an enabled schedule.

If configured, a notification service receives operational alerts, such as backup failures, listing availability or revenue-change warnings.

These external services process information under their applicable service terms and policies. Encrypted backups are stored by Google Drive. Google also handles authorization for the backup connection. This notice does not promise deletion of information already processed by an external service.

Retention and owner control

The owner controls the device, Drive folders, access credentials and backup configuration. Receipt corrections, voids and matching decisions preserve history rather than erasing earlier records. Revoking Drive access stops future authorized access but does not remove previously imported expense evidence or existing backup copies.

Remote backups do not currently have automatic retention deletion. The owner manages their removal separately. Clearing temporary PDF contents is not a guarantee of secure erasure from historical database pages or earlier snapshots. Requests about records or access should be directed to the application owner.

This information site

This static site describes the application and does not provide access to the private dashboard. It contains no sign-in, receipt upload, analytics script or embedded shop records. It is intended for hosting on GitHub Pages, where GitHub logs visitor IP addresses for security purposes. See GitHub's privacy statement for its hosting practices.

Questions

For questions about this private application, use the owner support email displayed on its Google authorization screen. This notice will be updated if the application's access or data processing changes.
